# FanDuel Multi-Sport DFS Optimizer

An interactive, multi-sport FanDuel Daily Fantasy Sports lineup optimizer. Build
optimal lineups under the salary cap, apply stacking + exposure constraints,
compare projections against consensus value, and upload official salaries via CSV.

**Sports:** MLB, NFL, NBA (year-round). **Site:** FanDuel Classic contest formats.

Live preview: open `index.html` in any browser, or enable GitHub Pages (below).

## How it works

- `index.html` — the single-page app (Tailwind CDN + vanilla JS). All optimization
  runs in the browser; no server, no account needed.
- `config.js` — FanDuel roster slots, salary caps, per-team limits, and scoring
  rules for each sport. Add a sport here + a data block.
- `data.js` — the player pool: salaries, projections, implied totals, and stats.
  Generated by `refresh.py` and refreshed daily by the GitHub Action.
- `refresh.py` — standalone daily refresher. Fetches live odds from
  [The Odds API](https://the-odds-api.com) and player stats from the public MLB
  StatsAPI and ESPN endpoints, then computes modeled projections + salaries.
- `gen_multi.py` — the original in-session generator (uses Perplexity's OpticOdds).
  Not used by the GitHub Action; kept for reference.

## Projections & salaries are MODELED

Salaries and point projections are modeled estimates — there is no official
FanDuel salary feed available to this tool. They are computed from live odds
(implied totals) and season-to-date player stats. To use **official FanDuel
salaries**, export the CSV from the FanDuel contest lobby and upload it with the
"Upload FanDuel CSV" button — your salaries override the modeled ones for that
session.

## One-time setup (GitHub Pages + daily refresh)

1. **Enable GitHub Pages.** Repo → Settings → Pages → Source: **Deploy from a
   branch**, branch `main`, folder `/ (root)`. Your site goes live at
   `https://<your-username>.github.io/<repo-name>/`.

2. **Add your Odds API key** (free tier available, ~500 requests/month — one daily
   refresh uses ~3). Get a key at https://the-odds-api.com, then:
   Repo → Settings → Secrets and variables → Actions → New repository secret →
   Name: `ODDS_API_KEY`, Value: your key.

3. **Run the refresh.** Repo → Actions → "Daily slate refresh" → Run workflow.
   This regenerates `data.js` and commits it; GitHub Pages redeploys automatically.

That's it. The Action runs daily at ~11 AM Eastern (before evening MLB slates).
Each run refreshes every sport with games on the slate; if a sport is in its
offseason or a data source is unreachable, it keeps the last good data block so
the site never breaks.

## Notes

- The Odds API is US sportsbooks only. Moneylines and totals drive the implied
  run/team totals shown in the Slate and Compare views.
- The optimizer enforces FanDuel's per-team limits (4 per team for MLB/NFL/NBA;
  MLB allows a 5th from the same team when one is the pitcher).
- All player names and stats come from public sources; this tool is for personal
  informational use and is not affiliated with or endorsed by FanDuel.
